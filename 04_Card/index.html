LINE 官方帳號與 GAS 5 步驟免費部署指南

1

申請 LINE 官方帳號與 Messaging API

前往 LINE Developers 主控台，建立 Provider 並開啟 Messaging API，取得 **Channel Access Token**。

2

貼入下方三合一 GAS 腳本

開啟 Google 試算表 ➔「擴充功能」➔「Apps Script」，把下方腳本複製貼上，並修改頂部的 `AGENT_CONFIG` 與 `LINE_ACCESS_TOKEN`。

3

部署 Web App 並選擇所有人

點擊右上「部署」➔「新增部署作業」➔ 選擇「Web 應用程式」，存取權選 **「所有人 (Anyone)」** 並複製獲得的 URL。

4

貼回 LINE Webhook URL 啟用網址

把 GAS Web App URL 貼回 LINE Developers 的 Webhook URL 欄位並點擊【Use Webhook】啟用驗證。
